# 原业务能力的正确接入点

[项目入口](../../../README.md) · [服务边界](../../architecture/service-contracts/README.md)

`643e73d` 的“八模块迁移完成”结论已撤回。统一数据库、worker 和运行记录只算基础设施；本次修复不恢复旧数据库，也不删除已有历史。

## 当前调用关系

```text
原文档索引的读取服务 ─┐
原图谱的事实读取服务 ─┼→ 上下文供应 → 资料版本 → 原倒排索引实现 → 索引产物
文件解析服务 ────────┘                                      ↓
                                                     上下文配置版本

数据集版本 → 模型供应 → 原训练参数构建函数 → LLaMA-Factory → 模型产物
                                                        ↓
                                              合并 / 部署 → 模型服务

岗位 Agent → 装配固定的 Harness、模型服务、上下文与索引版本 → 原生 Pi
                                                                ↓
                                                     调用已发布索引的检索服务
```

- 文档服务提供原文。操作员明确选择文档后保存资料快照，不抓取页面控件或回调输出。
- 图谱服务提供主体、关系、客体及文档来源。读取连接不补种、不重载、不写图；已有事实形成快照后可加入上下文或检索索引。
- 索引适配器复用原 `InvertedIndex` 业务实现，产物记录资料版本、文件摘要及检索实现摘要；更新资料不会改写旧索引。
- 模型供应直接使用原训练配置映射，按 CPT/SFT/DPO 校验数据结构，冻结数据文件及原生列描述，再通过原生 CLI 执行。执行队列负责进程、取消和日志，不决定模型、资料或界面参数。
- RAG 服务通过明确的索引读取接口和模型调用参数验证组合，不依赖当前页面、线程上下文或 SDK 导入替换；验证输出是证据，不自动进入供应库。
- 岗位装配读取具体版本。Pi 的检索工具只接受已发布索引标识和查询，不接受调用方指定文件路径、命令或其他项目索引。

## 已撤除的错误接法

通用 `OpenAI` 替换器、旧页面的供应覆盖面板、依赖“当前回调运行”的训练登记、任意输出 JSON 直接发布为资料均已移除。旧发布 URL 返回 410，旧回调的供应覆盖参数明确拒绝，历史记录继续可读。

原固定测试预设里的上下文附加保留为兼容测试功能，不能拿它当成新供应层。原八个界面仍可用于历史实验、图谱和多模态操作及结果核对；它们没有因为接入日志就成为新的领域服务。

## 明确的范围

本次接入原文档、倒排检索、图谱事实、训练配置和 RAG 验证服务。原多模态、GUI、CTR、偏好采集和监控界面继续兼容使用；尚未将它们的所有能力重构成岗位工具或模型服务，不能宣称全量迁移完成。

当前岗位运行适配器为 Pi，模型协议为文本消息服务。vLLM 的实际业务部署、其他 Harness、自动来源同步、向量索引和 MLflow 仍按架构文档的实施状态说明。
