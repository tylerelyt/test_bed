启动与退出实测发现并修复了两个问题：信号处理器调用 `Event.set()` 可能重入非重入锁，造成旧 worker 退出死锁；启动脚本只检查标识文件存在，可能把旧 PID 当成本次进程。现在信号处理器仅设置退出标记，进程关闭时再停止队列与原生进程；脚本核对本次子进程 PID 并等待已启动子进程退出。
