# 工作台交互约定

[返回项目](../../README.md) · [使用指南](../README.md)

本次按企业后台的资源管理方式整理交互，保留上下文供应、模型供应、岗位 Agent 的职责和既有业务接口。当前面向桌面浏览器，不将移动端适配列入支持与验收范围。

## 参考依据

- [Cloudscape：资源列表](https://cloudscape.design/patterns/resource-management/view/table-view/)：先展示已有资源、状态及可用操作，再进入创建或详情。
- [Cloudscape：侧栏导航](https://cloudscape.design/patterns/general/service-navigation/side-navigation/)：导航按业务对象和用户任务组织，面包屑与导航保持一致。
- [Cloudscape：对象详情中的标签](https://cloudscape.design/patterns/resource-management/details/details-page-with-tabs/)：标签用于同一对象的相关信息，跨功能页面通过导航进入。
- [PatternFly：分步流程](https://www.patternfly.org/components/wizard/design-guidelines/)：复杂且有先后依赖的任务分步完成；简单的数据录入保留单页表单。

这些规范用于选择交互方式；本项目继续沿用现有 React、Next.js 与界面样式，没有引入另一套组件框架。

## 页面与操作

| 页面 | 默认展示 | 主要操作 |
| --- | --- | --- |
| 岗位与 Agent | 岗位、Agent 及采用状态的列表 | 新建岗位、设置 Agent、进入配置与试运行 |
| 资料库 | 资源名称、类型、版本与来源 | 新建、文件导入、查看详情、编辑新版本 |
| 供应配置 | 配置版本、资源数量与预算 | 组合资源、检查装配、编辑新版本 |
| 检索索引 | 索引及固定资料版本 | 构建索引、检查检索、生成岗位引用 |
| 资料库 → 接入业务资料 | 一次选择一个来源 | 从文档或图谱保存资料快照，查看保存结果 |
| 模型服务 | 已接入的服务 | 接入服务、查看调用配置 |
| 训练数据集 | 固定数据快照 | 导入、查看元数据、提交训练 |
| 模型产物 | 已有权重及作业产物 | 登记、查看来源、训练、合并或部署 |
| 作业管理 | 类型、状态、时间及筛选 | 查看结果、前往产物、查看日志、取消活动作业 |

列表页不同时展开创建表单。新建或编辑时集中处理一个对象；保存后显示真实结果，未提交的字段不会触发业务操作。岗位 Agent 先列表、再进入具体 Agent；详情内的“配置与版本、试运行、运行记录”均属于当前 Agent，不再设置全局的“发布与运行”页，也不强制用户按步骤向前走。模型和上下文由操作员明确选择。

侧栏的子菜单直接位于所属栏目下；资料库、供应配置、模型服务等是资源入口，原处理与验证工具在各自供应栏目内展开，不与资源入口混排。获取文档或图谱快照从资料库发起，不作为另一个独立管理对象。每页只显示一个主标题，详情面包屑包含对象名称。

从 Agent 配置进入模型服务或上下文配置时，地址保留返回位置，页面显示带 Agent 名称的返回按钮。可以继续准备所需资料，完成后返回同一个 Agent；新资源仍由操作员明确选择。供应作业保留发起它的资源入口，结果指向真实生成的资源。

功能页面、资源详情、Agent 内的页签、版本和运行结果通过地址参数定位。刷新及浏览器前进后退按地址恢复；地址中的位置优先于旧会话偏好。旧模块位置在没有明确地址时迁入所属供应页面。Agent 未提交的模型和上下文选择仅暂存在当前浏览器会话；其他未提交表单仍为本地编辑状态，均不属于后端已保存版本。

## 验证范围

检查列表与表单切换、资源保存与详情、文件导入后的作业结果、来源到索引的连接、岗位原生 Pi 试运行与采用、地址与浏览器历史，以及桌面布局。原训练、检索、模型供应及权限规则继续由既有业务服务执行，不能以交互检查代替模型效果验收。
