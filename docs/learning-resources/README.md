# 学习资源与阅读路径

[项目说明](../../README.md) · [文档导航](../README.md)

围绕一次可观察的实验选择资料，读完后回到实现和结果核对，避免把概念文章直接当成项目功能说明。

1. 从[索引与检索](../search-recommendation/README.md)理解材料如何进入候选结果。
2. 用[RAG 与 OAG](../rag/README.md)观察回答如何使用文档和关系事实。
3. 用[上下文工程](../context-engineering/README.md)核对模板、工具、资源与历史装配。
4. 根据任务选择[训练反馈](../llmops/README.md)、[多模态](../multimodal/README.md)或[桌面智能体](../gui-agent/README.md)。

[原有资料链接目录](lectures/README.md)保留外部资源。其版本、可访问性和适用性需使用时核对，不以旧讲义中的推荐文字代替验证。
