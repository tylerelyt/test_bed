# 学习资料的选择与使用

[项目说明](../../../README.md) · [当前模块说明](../README.md)

先通过工作台完成一次文档检索和结果核对，再按任务选择图谱、上下文装配、训练或桌面自动化资料。阅读方法论文时，应把“论文方法”“讲义示例”和“本仓库实际调用路径”分开记录。

资料名称与链接可以保留，但外部文章、课程、工具和模型的可用性、价格、版本与适配性需要使用时另行确认。本页不对旧材料中的排名、推荐程度或更新时间作新的背书。

## 怎样验证

1. 为要解决的问题选一篇主资料，记录它解释的机制。
2. 在仓库中找到对应实现入口，核对示例是否实际接入。
3. 用一个小任务观察结果，并记录与材料假设不同的地方。

## 使用边界

外部资料是补充阅读，不能替代本项目的启动说明和具体版本验证。
