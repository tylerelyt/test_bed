# 本次修复的接入边界

本次不恢复旧数据库，不改历史运行、模型或上下文版本。统一存储、worker 和兼容页面保留；它们只负责基础设施与观察，不被当成供应服务。

入口按业务归属组织：资料、索引、召回、图谱及 MCP 归上下文供应，训练评测和图像生成归模型供应，GUI Agent 归岗位 Agent，监控归运行环境。“作业管理”仅管理供应服务实际提交的 `platform_jobs`；原回调记录不拼入列表，不借用作业接口查看或取消，历史留在对应能力内。

| 入口 | 服务调用 | 交付物 | 消费方 |
| --- | --- | --- | --- |
| 上下文供应的资料来源 | 解析服务、原文档索引服务的读取接口 | 带来源、摘要和版本的资源 | 上下文包 |
| 上下文供应的图谱来源 | 原 JanusGraphBackend 的实体关系读取接口 | 主体、关系、客体、文档来源组成的事实快照 | 资料索引；不重载图谱 |
| 上下文供应的索引构建 | 原倒排索引实现，经独立适配器构建 | 不可变索引及其文档版本清单 | 检索检查、岗位工具 |
| 模型供应的训练 | 数据集校验 → 原训练参数构建函数 → LLaMA-Factory 原生 CLI | 训练记录、日志、有效模型产物 | 合并、部署、模型登记 |
| 模型供应的部署 | 已登记模型产物 → vLLM 原生服务 | 已就绪的模型服务配置 | Agent 发布 |
| Agent 装配 | 上下文包/索引版本 + 模型服务 + Pi 适配器 | 固定发布包 | 原生 Pi 执行 |
| 原业务页面与运行记录 | 原操作及其历史回放 | 测试与观察证据 | 人工验证；不自动进入供应链 |

必须移除：替换 SDK 导入的通用模型覆盖、把供应配置拼进任意界面字段、直接发布界面输出 JSON、依赖“当前回调运行”的训练登记。旧固定测试预设的上下文附加属于原兼容测试功能，不是新平台接入方式。

验收按服务边界分别证明：来源确实来自业务服务；版本更新不改变旧包；其他项目不能读取索引；岗位工具实际调用对应版本的检索；训练登记由模型供应发起且不依赖 Gradio 回调。回调测试和页面测试只能作为回归检查。

## 验证与限制

- 服务测试覆盖原文档来源、图谱只读接口、索引版本固定、摘要检查、项目归属、显式 RAG 模型依赖和禁止旧回调供应覆盖。
- 原生 Pi 验收使用本地协议测试模型，实际执行检索工具并返回固定索引中的制度及文档来源；不代表真实模型的岗位能力。
- CPT/SFT/DPO 分别用本机微型权重执行 LLaMA-Factory 0.9.1，确认训练产物由模型供应登记，且该进程未导入 Gradio 或旧回调运行时。此检查不评价模型质量。
- 原倒排索引的 IDF 从 `log(N/df)` 改为 `log((1+N)/(1+df))+1`，避免只有一份资料时所有命中得分为零而被过滤。检索分数因此变化；原始资料不改，新索引记录算法摘要，既有发布不会静默替换实现。
- vLLM 适配存在，本机没有 vLLM，部署尚未实机验收；其他 Harness 及其他原模块的服务化继续保留为明确未完成项。
